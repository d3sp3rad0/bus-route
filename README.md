# Маршрут автобуса

Бесплатный статический сайт для телефона. Водитель диктует или вводит точки маршрута, сайт собирает ссылку и открывает готовый автомобильный маршрут в Яндекс Картах.

Без Telegram-бота, сервера, Docker, OpenAI API и Yandex API.

## Как открыть локально

Откройте `index.html` в браузере.

## Как опубликовать бесплатно на GitHub Pages

1. Создайте новый публичный или приватный репозиторий на GitHub.
2. Загрузите в него файлы из этой папки:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `manifest.webmanifest`
   - `.nojekyll`
3. Откройте настройки репозитория: `Settings` -> `Pages`.
4. В `Build and deployment` выберите:
   - `Source`: `Deploy from a branch`
   - `Branch`: `main`
   - Folder: `/root`
5. Нажмите `Save`.

Через минуту GitHub покажет ссылку вида:

```text
https://username.github.io/repository-name/
```

Эту ссылку можно отправить отцу. Он открывает ее на телефоне, вводит или диктует маршрут и нажимает `Открыть в Яндекс Картах`.

## Как пользоваться

Пример фразы:

```text
Курск. Россошь. Волгоград. Мамаев курган. Обратно в Курск.
```

Сайт превратит фразу в список точек, найдет координаты через OpenStreetMap Nominatim и сформирует ссылку для Яндекс Карт.

```text
https://yandex.ru/maps/?mode=routes&rtext=51.730361,36.192647~50.198282,39.567266~48.707103,44.516939&rtt=auto
```

Километраж и время показывает уже Яндекс Карты после открытия маршрута.

Координаты запоминаются только временно, пока открыта вкладка. После закрытия страницы постоянный кэш координат не хранится.

## Безопасность и приватность

- На сайте нет регистрации, паролей, Telegram-токенов, OpenAI API ключей и Yandex API ключей.
- Сайт не отправляет маршруты на ваш сервер, потому что сервера нет.
- Названия точек отправляются в OpenStreetMap Nominatim только для поиска координат.
- Готовый маршрут открывается в Яндекс Картах, поэтому координаты маршрута передаются Яндексу.
- В браузере хранится только короткая история последних маршрутов: до 5 записей с названиями точек. Ее можно удалить кнопкой `Стереть`.
- Старые кэши координат, созданные предыдущими версиями сайта, удаляются автоматически при открытии страницы.

## Автоматический обход южного направления

Если сайт видит маршрут из Курска в Беларусь или обратно, он автоматически добавляет промежуточные точки:

```text
Орёл
Брянск
```

Это сделано, чтобы Яндекс Карты сначала увели маршрут севернее по территории РФ, а не строили дорогу вдоль границы с Украиной. Дальше маршрут идет к указанной водителем точке: Минску, Витебску, Могилёву или другому городу. Это не заменяет проверку актуальной дорожной обстановки перед поездкой.

## Ограничения бесплатной версии

- Сайт не считает расстояние и время сам.
- Сайт не использует GPT, поэтому не умеет надежно оптимизировать порядок точек.
- Для поиска координат используется бесплатный OpenStreetMap Nominatim. Сайт делает запросы аккуратно, примерно по одной точке в секунду.
- Если браузерная кнопка микрофона не работает, используйте микрофон на клавиатуре телефона в поле ввода.
- Если Яндекс неоднозначно понял точку, ее можно поправить вручную в списке.
